# Liberty Infinity — MPC ROMpler

Liberty Music Software. Instrument autonome Akai MPC, lecture de multisamples originale, interface rétro argent et LCD bleu. Objectif : 100 presets Factory originaux.

Phase initiale : prototype de lecture PCM, validation SDK ARM32/ARM64, puis interface personnalisée et banque sonore. Aucun contenu reFX n'est distribué.

SDK : https://github.com/inmusic-software/mpc-plugin-builder-sdk (MPC OS 3.10.1+, support externe bêta).
