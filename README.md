CI : 500 zones testées pour signal non nul, fini et borné, et contrôle des sons bouclés, puis compilation et packaging. Ces tests ne remplacent pas l'écoute ni la validation CPU/RAM et UI sur MPC. Installer seulement pour essais, sauvegarder ses projets. SDK MIT épinglé au commit e78bad508a305a92443758eb2bc8b428e9e7a687. Aucun contenu reFX.

## Premium Sound Engine (v0.6)

Remplacement de la banque précédente par 2000 zones mono PCM24 44,1 kHz (100 sources × 5 notes × 4 niveaux de vélocité), 2 secondes par zone, 529,2 Mo sur disque. Les presets superposent de 1 à 4 sources distinctes du même groupe, avec panoramique et légère transposition ; stéréo à la sortie, pas des prises stéréo. Deux caches de presets décodés en int32, maximum théorique d'environ 56,45 Mo PCM par instance, hors DSP et buffers temporaires. Chargement asynchrone pendant l'utilisation, premier son chargé dans le constructeur ; le changement de preset coupe les anciennes voix lorsque le nouveau cache est prêt, les notes reçues avant la disponibilité du nouveau preset sont ignorées. Aucun accès fichier dans process(). Source synthétique originale rendue hors ligne, notamment pianos à cordes raides, ensembles, supersaws ; ce ne sont pas des enregistrements acoustiques. Interpolation sinc fenêtrée 12 taps et 7 bandes anti-alias, filtrage hors ligne, fondu de boucle 40 ms. 64 notes sur Mac, plafond prudent 32 ARM64 MPC et 24 ARM32 ; la polyphonie réelle et l'aliasing restent à mesurer sur matériel. Tests de chaque preset/racine/vélocité et stress 64 notes sur hôte CI. Les résultats ne valent pas validation d'écoute ou certification temps réel MPC. La banque de la v0.5 n'est plus compatible avec le nouveau moteur ; réinstaller le dossier complet.

## Professional ROMpler (v0.8.0, first import stage)

Offline importer `tools/import_multisamples.py` (Python, numpy, scipy) creates a separate Factory.pcm and Factory.pcm.map from user-owned WAV files. Use the sample manifest in docs. Mono conversion for stereo WAV, polyphase conversion, monophonic root detection or explicit root, key/velocity range mapping to existing five roots/four velocity bins, optional shared peak normalization, loop points in original WAV frames, and up to four source layers with independent gain/pan/tuning. The runtime reads the optional map at startup, uses per-layer settings and loop regions, and keeps the original factory path when no map is present. Stop the host and install both files together in Content (on Mac, in the app Resources/Content; this invalidates the ad-hoc signature, rebuild/re-sign for testing). Back up original content; a replaced source slot can also affect factory presets which reuse it. Names and preset numbers remain factory names; no graphical editor yet. Two seconds maximum per zone after conversion, longer samples truncated, loops exceeding the limit rejected; stereo downmix can cancel out-of-phase material. No arbitrary runtime mapping, no streaming and no new acoustic recordings. No on-device measurements yet. The importer is an external development utility, not a native MPC browser.

## Stereo HD Sample Engine v0.9.1

The original LINFHD01 factory file remains unchanged. Personal banks append PCM24 mono/stereo data at their original rate (8–192 kHz); LINFMAP2 X records store offset, frame count, channel count, sample rate, root, loop start/end and crossfade. LINFMAP1 and the original factory remain readable. The 5-root / 4-velocity grid can reference the same imported sample without duplication. Playback uses source-rate/root compensation and independent L/R interpolation and crossfade. Samples are up to 120 seconds in the editor, subject to a 48 MiB decoded PCM budget per patch cache (two slots, excluding DSP and allocator overhead) and a 2 GB bank limit for ARM32. A rejected export does not replace the original. Loading is off the audio thread, by preset and referenced zones, not streaming and not on-demand per MIDI note. Mac Studio export is native AVAudioFile plus PCM24 writer, no Python dependency; legacy Python importer remains available for old format. Root detection is intended for stable monophonic material, explicit root recommended. Source slots can still affect other presets using them. Synthetic stereo test covers duration beyond two seconds and distinct channels; actual acoustic recordings, comparative device CPU/RAM and visual/subjective validation remain pending. Streaming design: independent background reader, preallocated per-source ring buffers and underrun counters, never file IO or allocation from process(); do not enable until stress/underrun tests pass.

## Disk Streaming Engine v0.9.2 (experimental, opt-in)

Multisample Studio has a new unchecked Streaming disque (expérimental) option. LINFMAP3 uses the same PCM payload and X records as LINFMAP2; only extended samples longer than 176400 frames are streamed. Legacy Factory and LINFMAP1/2 remain fully resident. The first 16384 frames per unique streamed sample are resident (including mono/stereo channels); four-way shared cache uses fixed 4096-frame pages with sinc guard frames, 128 pages on ARM32 and 256 elsewhere, plus a fixed SPSC request ring. The worker fills pages from disk, prioritizes queued playback requests before switching patches, and services a lookahead of three pages; loop-start prefetch is included. No file I/O, allocation or waiting in render. A missing page returns zero and increments a missing-channel-read counter (not a count of distinct audio frames); queue overflow and I/O failures have independent counters. No automatic dropout masking or certification. Peak PCM still includes two resident slots (48 MiB each), page storage (~4/8 MiB), DSP and metadata; memory may increase for small banks. The native comparison test uses a synthetic 30-second stereo recording with the same source shared across 8/16/32/64 voices, 48k/128, two seconds per case, real-time paced. It reports mean/p95/p99/max DSP budget, over-budget blocks, active slot PCM bytes, page bytes and missing reads/drops/errors. Exact distant-page samples are compared against fully resident playback; misses in the timed comparison are reported, not silently treated as a real-time pass. Not a worst-case distinct-source benchmark, not an acoustic recording, not actual MPC RAM/CPU; physical SSD/SD, loop, rapid preset switches, polyphony and long duration listening must be validated before enabling streaming by default. 2 GB bank and 120 s per sample import limits remain.

## Premium Acoustic Library v0.9.3 — articulation groundwork

No new acoustic WAV recordings are bundled: the 100 original Factory presets remain synthetic source renders. Studio can now assign four layer roles in addition to Normal: Round Robin (one group of at least two layers, alternates per MIDI note, reset on preset switch/reset), VelocityLow/VelocityHigh (one pair, smooth complementary blend at velocities 48–80, using the existing zone grid), ReleaseSample (one layer, starts on effective note-off after sustain, independent one-shot tail). Each role occupies one of the four layer slots; the release voice remains allocated while a note is held after the attack finishes. Export writes optional A patch/layer/role records following L records in LINFMAP2/3; older versions cannot read banks with A records. Older banks stay readable. Raw sample preview is not an articulation preview. RMS normalization is optional, shared across all samples within a source, target -18 dBFS RMS with peak ceiling -1 dBFS and maximum gain x4; it is not LUFS or perceptual loudness normalization. Factory test now writes an objective per-preset RMS and peak report, not listening certification. Streaming requests are throttled to per-block/voice, deduplication has four ways and skips already-ready pages; streaming test cases extended from 2 to 6 seconds. No physical hardware or acoustic recording validation yet. See docs/acoustic-library.md for source requirements.
