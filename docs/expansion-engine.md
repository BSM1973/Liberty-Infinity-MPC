# Expansion Engine v0.9.8 — MPC priorité absolue

Factory 1 reste incluse (indices 0–99). Slots 01–04 réservés, 100 presets chacun, indices 100–499. Ne jamais déplacer/réattribuer un slot utilisé dans un projet ; conserver UUID et contenu immuables. Les emplacements sont visibles sous LIB 1–4 dans le sélecteur Sound ; noms réels exposés au host via programs/formatValue, affichage dynamique à vérifier sur MPC. Redémarrer le plugin après installation, hôte arrêté. Emplacements vides silencieux.

Chaque extension dans Content/Expansions/01..04 contient Library.pcm (8 octets LINFEX01 puis PCM24 little-endian interleaved), Library.map UTF-8 et License.txt. Mac test utilise ~/Library/Application Support/Liberty Music Software/Liberty Infinity/Expansions, sans modifier le bundle signé. Ne pas écraser Factory.pcm. Exemple de map : LINFEXP1, I uuid-minuscule, N "Collection", P 0 "Preset", L 0 0 1 0 0 0 (patch couche gain pan cents rôle), X 0 0 2 2 8 44100 2 44100 60 0 44100 0 (patch couche zone vélocité offset longueur canaux fréquence fondamentale début fin crossfade). Toutes les 20 zones par couche obligatoires, données partagées possibles via offset. Rôles 0..4. License.txt: LINFLIC1 <uuid> DEMO. Limite 48 Mio PCM décodé par preset, 2 Go par fichier. Extensions chargées en RAM à la demande par le worker, pas de streaming des extensions dans cette étape. PCM Factory inchangé.

Les métadonnées et le fichier de licence DEMO sont validés, mais modifiables. Il ne s'agit pas d'une protection commerciale. Les licences payantes devront utiliser une signature numérique vérifiée hors ligne avec une clé publique Liberty et une procédure de délivrance des droits. Aucun secret commercial n'a été créé. Outil de fabrication et installation/listage sur ordinateur disponible : `python tools/expansion_pack.py build manifest.json dossier-pack`, puis `python tools/expansion_pack.py install dossier-pack chemin/Content 1` ou `list chemin/Content`. Il crée Cover.png (image fournie ou couverture typographique), PROVENANCE.json et le PCM, refuse un slot occupé. Le gestionnaire graphique natif dynamique et l'affichage des couvertures sur MPC restent à implémenter. Validation matérielle MPC ARM32/ARM64 requise. Mac est un outil de vérification, pas un produit commercial.

### Exemple de manifeste de fabrication

```json
{"id":"12345678-1234-1234-1234-123456789abc","name":"Collection Demo","entitlement":"DEMO","presets":[{"index":0,"name":"Piano","layers":[{"zones":[{"wav":"piano.wav","root":60,"source":"Votre enregistrement","rights":"Vos droits de redistribution"}]}]}]}
```
Les chemins WAV sont relatifs au manifeste. Facultatif : cover (PNG), gain/pan/cents/role par couche, key_min/key_max/vel_min/vel_max/loop/crossfade par zone. Le programme s'exécute sur ordinateur, pas sur MPC ; pip install numpy scipy pillow. Quitter l'hôte avant installation et ne jamais réattribuer un slot d'un projet existant.
