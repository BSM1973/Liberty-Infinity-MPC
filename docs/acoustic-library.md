# Premium Acoustic Library — source intake

No recordings have been acquired or licensed. For commercial distribution of the raw samples within a ROMpler, use owned recordings or a license explicitly permitting redistribution in a sample-based virtual instrument. Ordinary royalty-free music production licenses may not grant this right.

| Family | Desired recordings | Articulation plan |
|---|---|---|
| Acoustic piano | stereo, multiple velocities, pedal up/down | soft/hard pair and release |
| Vintage electric piano | direct and amp recordings | soft/hard pair, release |
| Acoustic/electric guitar | picked and plucked notes | 2–3 round robins, release |
| Orchestral strings | sustained and short articulations | soft/hard pair, optional release |
| Brass and winds | sustained and tongued notes | soft/hard pair, round robin where appropriate |
| World instruments | recorded plucks and strikes | 2–3 round robins |

For each WAV retain provenance, creator, license text/version, evidence of redistribution rights, note, velocity range, articulation, take index, sample rate, channels, and original file hash. Do not include recordings with unclear licensing. The existing five-root/four-velocity grid is still a limitation; use a dedicated source slot per articulation. Four layer slots are shared by normal/round-robin/velocity/release roles.

Acceptance: listen to each preset across register and velocity, repeated strikes, note-off and sustain, loop seams, stereo balance and peak/RMS; run 60-second hardware streaming tests with distinct sources, report underruns, CPU and RAM. Record pass/fail separately from CI.
